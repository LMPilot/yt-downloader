# YT Downloader

Проста програма для завантаження відео з YouTube (одне відео, плейлист або цілий канал) на основі [yt-dlp](https://github.com/yt-dlp/yt-dlp) з інтерфейсом на [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter).

Кожне відео зберігається в **окрему папку**, названу за назвою відео:

```
Downloads/YT/
├── Назва першого відео/
│   ├── Назва першого відео.mp4
│   └── info.txt
└── Назва другого відео/
    ├── Назва другого відео.mp4
    └── info.txt
```

`info.txt` (UTF-8): **1-й рядок** — назва відео, **рядки 2–4** — порожні, **з 5-го рядка** — повний опис.

## Можливості

- Посилання на відео, плейлист або канал (`https://www.youtube.com/@назва` — вкладка «Відео» підставляється автоматично).
- Режими: **Одне відео**, **N відео з каналу** (останні N), **Усі відео з каналу**.
- Якість: Найкраща, 2160p, 1440p, 1080p, 720p, 480p, 360p (якщо потрібної немає — береться найближча), результат у MP4.
- **Лише аудіо (MP3)** з бітрейтом 320 / 192 / 128 кбіт/с.
- Галочка «Зберігати назву та опис» (`info.txt`).
- Вибір папки для завантаження вгорі вікна (див. нижче), програма її запамʼятовує.
- Прогрес (відео k/N, відсотки, швидкість), журнал, кнопка «Скасувати».
- Помилка на одному відео не зупиняє завантаження каналу.
- Якщо відео вже завантажене — повторно не качається.

## Готовий .exe (без Python)

Найпростіше — завантажити готовий `yt-downloader.exe` і запустити подвійним кліком.

- **Releases** (стабільні версії): сторінка репозиторію → **Releases** → останній реліз → файл
  `yt-downloader.exe` або `yt-downloader-windows-with-ffmpeg.zip` (усередині exe і `ffmpeg.exe`,
  нічого додатково ставити не треба — просто розпакуйте обидва файли в одну папку).
- **Actions** (найсвіжіша збірка з гілки): вкладка **Actions** → workflow **Build Windows exe** →
  останній зелений запуск → унизу в розділі **Artifacts** архів `yt-downloader-windows`
  (усередині `yt-downloader.exe`). Потрібно бути залогіненим у GitHub.

Для роботи exe потрібен **FFmpeg**: або покладіть `ffmpeg.exe` в ту саму папку, що й
`yt-downloader.exe`, або встановіть його в систему (`winget install Gyan.FFmpeg` чи
`choco install ffmpeg`). Бажано також встановити **Deno** або **Node.js** (див. нижче).

### Оновлення програми

Під час запуску exe тихо перевіряє (у фоні, без затримки інтерфейсу), чи є на GitHub новий
реліз. Якщо є — над кнопками зʼявляється зелена панель із кнопкою
**«Оновити до версії X.Y.Z»** (а **«Що нового»** показує опис змін). Перевірити вручну можна
кнопкою **«Перевірити оновлення»** внизу вікна; поточна версія показана там само і в заголовку.

Після натискання «Оновити…» програма:

1. завантажує новий `yt-downloader.exe` у ту саму папку (файл `yt-downloader.exe.new`) і
   звіряє його розмір та SHA256 з файлом `yt-downloader.exe.sha256` з релізу;
2. закривається, а невеликий скрипт `yt-downloader-update.cmd` замінює exe на новий
   (попередня версія лишається поруч як `yt-downloader.exe.old`; якщо заміна не вдалась —
   стара версія відновлюється) і запускає програму знову.

Під час завантаження відео оновитись не можна — спершу дочекайтесь кінця або скасуйте.
Папка з exe має бути доступна для запису (наприклад, не `C:\Program Files`). Якщо щось
пішло не так, новий exe завжди можна завантажити вручну зі сторінки **Releases**.
Без інтернету перевірка просто пропускається (у журналі буде один рядок).

Якщо програма запущена з вихідного коду (`python app.py`), вона лише повідомить про нову
версію — оновіть код командою `git pull`.

Windows SmartScreen може попередити про «невідомого видавця» — натисніть
**Докладніше → Виконати все одно** (exe не підписаний сертифікатом).

## Папка для завантаження

Вгорі вікна є рамка **📁 Папка для завантаження** з повним шляхом:

- **Обрати…** — відкриває стандартне вікно Windows для вибору папки;
- **Відкрити** — відкриває папку в Провіднику;
- шлях можна також вписати вручну.

За замовчуванням це `Downloads\YT` у вашій домашній папці. Обрана папка (а також режим,
якість, бітрейт і N) запамʼятовується між запусками у файлі
`%APPDATA%\yt-downloader\settings.json` (на Linux/macOS — `~/.config/yt-downloader/`).

Перед стартом програма створює папку, якщо її немає, і перевіряє, що в неї можна писати —
інакше показує помилку й пропонує обрати іншу. Для одного відео, N відео чи всього каналу
кожне відео потрапляє в **окрему підпапку всередині обраної папки**.

## Встановлення з вихідного коду (Windows 10/11)

1. Встановіть **Python 3.10+** з [python.org](https://www.python.org/downloads/) (під час встановлення поставте галочку **Add Python to PATH**).
2. Встановіть **FFmpeg** (потрібен для MP4 та MP3) і **Deno** (потрібен yt-dlp, щоб YouTube віддавав усі формати). У PowerShell:

   ```powershell
   winget install Gyan.FFmpeg
   winget install DenoLand.Deno
   ```

   Після встановлення **закрийте й знову відкрийте** PowerShell (щоб оновився PATH).
   Замість встановлення FFmpeg можна просто покласти `ffmpeg.exe` у папку з програмою.
3. Завантажте цей репозиторій (кнопка **Code → Download ZIP** або `git clone`) і в його папці виконайте:

   ```powershell
   pip install -r requirements.txt
   ```

## Запуск

```powershell
python app.py
```

Вставте посилання, оберіть режим і якість, натисніть **Завантажити**.

### Оновлення yt-dlp

YouTube часто змінюється, тож якщо завантаження раптом перестали працювати — оновіть yt-dlp:

```powershell
pip install -U "yt-dlp[default]"
```

## Збірка .exe самостійно

PyInstaller збирає exe лише під ту систему, на якій запущений, тому збирати треба на Windows.
У PowerShell у папці репозиторію:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт встановить залежності та PyInstaller, запустить тести й збере
`dist\yt-downloader.exe` (один файл, без консольного вікна). Якщо `ffmpeg.exe` є в PATH
(зокрема встановлений через Chocolatey), його копія теж покладеться в `dist\` — цю папку
можна переносити на інший компʼютер. Параметри: `-SkipTests`, `-SkipInstall`.

Поруч зʼявляється `dist\yt-downloader.exe.sha256` (контрольна сума для автооновлення), а
у властивостях exe (вкладка «Подробиці») — номер версії.

На GitHub те саме робить workflow `.github/workflows/build-windows.yml` (на кожен push у
`main`/робочу гілку, вручну через **Run workflow** та на теги `v*`).

## Як випустити нову версію

Номер версії задається в одному місці — файлі `version.py`.

1. Змініть `__version__` у `version.py`, наприклад на `"1.1.0"`
   (формат `МАЖОРНА.МІНОРНА.ПАТЧ`; порівнюються числа, тож `1.10.0` новіша за `1.9.0`).
2. Закомітьте й запуште зміну в `main`:

   ```powershell
   git commit -am "Версія 1.1.0"
   git push
   ```

3. Створіть і запуште тег **з тим самим номером** і літерою `v`:

   ```powershell
   git tag v1.1.0
   git push origin v1.1.0
   ```

Workflow перевірить, що тег збігається з `version.py` (інакше збірка впаде з помилкою),
запустить тести, збере exe і створить **Release** з файлами `yt-downloader.exe`,
`yt-downloader.exe.sha256` та `yt-downloader-windows-with-ffmpeg.zip`. Опис змін генерується
автоматично; його можна відредагувати на сторінці релізу — саме він показується в програмі
за кнопкою «Що нового».

Після цього всі, у кого встановлений exe, при наступному запуску побачать кнопку
«Оновити до версії 1.1.0». Чернетки та релізи з позначкою *pre-release* програма ігнорує.

## Структура

- `downloader.py` — логіка завантаження (без GUI): налаштування yt-dlp, назви папок, `info.txt`.
- `app.py` — графічний інтерфейс на CustomTkinter.
- `settings.py` — збереження налаштувань (папка, якість, режим) між запусками.
- `version.py` — номер версії програми (єдине місце, де його треба змінювати).
- `updater.py` — перевірка нових релізів на GitHub, завантаження і заміна exe.
- `version_info.py` — генерує дані версії для властивостей exe (використовує `build.ps1`).
- `build.ps1` — збірка `dist\yt-downloader.exe` через PyInstaller.
- `.github/workflows/build-windows.yml` — збірка exe на GitHub Actions і релізи.
- `tests/` — юніт-тести.

Програма призначена для особистого використання. Завантажуйте лише той контент, на який маєте право.
